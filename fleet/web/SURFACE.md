# Fleet Operations Console Surface Brief

- **Mode:** Operate. A local Fleet operator needs to diagnose readiness,
  attention, active work, and recovery causality quickly.
- **Primary task:** identify the narrowest unhealthy scope, then inspect the
  authoritative Run facts that explain it.
- **Constraints:** read-only, loopback-only, fixed light identity, desktop
  density with complete phone observation, no raw prompts or reasoning.
- **Direction:** a layered operations ledger. Service state forms the header;
  attention interrupts the normal flow only when necessary; Fleet and Run
  rows carry the working surface instead of metric cards.
- **Memorable moment:** a Run timeline and evidence ledger meet at the current
  safe checkpoint, making restart recovery understandable without logs.
